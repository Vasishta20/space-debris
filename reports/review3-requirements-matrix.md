## Explicit architecture decisions

The exact rubric requires PostgreSQL for the local-first architecture, while the project proposal additionally names Cassandra and Hive as target components. PostgreSQL is verified; Cassandra and Hive remain missing/unverified. The PySpark model and prioritization score are separate: the former predicts object type; the latter ranks bounded screening candidates using distance and relative velocity and is not calibrated collision probability.
